# Yip Zi Wun Universe

Version 1 of **Yip Zi Wun Universe**, a personal digital space built around the idea:

> Building my own universe, one project at a time.

This is not a resume site or job-hunting page. It is a project-driven personal homepage for growth, creation, technology exploration, and future-facing work.

## GitHub Pages

This repository is designed to run directly on GitHub Pages.

1. Push the repository to `main`.
2. Open the repository settings on GitHub.
3. Go to **Pages**.
4. Set the source to `Deploy from a branch`.
5. Select `main` and `/root`.
6. Visit `https://smg0128.github.io`.

## Tech Stack

- HTML
- CSS
- JavaScript
- GitHub REST API without token

No React, Vue, Next.js, Tailwind, backend service, or build step is required.

## How to Modify Content

- Main identity and GitHub username: edit `CONFIG` in `script.js`.
- Birthday and graduation date: edit `birthDate` and `graduationDate` in `script.js`.
- Current mission progress: edit `missionProgress` in `script.js`.
- Project nodes: edit the Project Universe section in `index.html`.
- Visual style: edit colors, spacing, glass effects, and animations in `styles.css`.
